# Interface icons

Udhaar uses the official **Nucleo Sharp Essential** icon family by Nucleo.

- Source: https://nucleoapp.com/free-sharp-icons
- Package: `nucleo-sharp-essential` 1.0.1
- License terms: https://nucleoapp.com/license

`scripts/build-icons.mjs` renders a curated subset to static SVG in
`public/js/ui/icons.js`. The browser does not download React or an icon library
runtime. Brand marks and editorial illustrations are separate from UI glyphs.
